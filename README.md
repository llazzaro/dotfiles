## What is this?

This is my dotfiles configuration files.


## How to install configuration?

Install git first, then clone and run the installer:

```
git clone https://github.com/llazzaro/dotfiles.git ~/.dotfiles
cd ~/.dotfiles
./install.sh
```

Review `bin/bootstrap.sh` before running it — it installs packages,
clones helper repos, and symlinks config files into your `$HOME`.

## Neovim

Neovim configuration lives in `nvim/` and is installed to
`~/.config/nvim` by the bootstrap script.
